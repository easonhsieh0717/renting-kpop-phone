# CRON_SECRET 金鑰生成器

## 🔐 **推薦的 CRON_SECRET 值**

以下是一個安全的 CRON_SECRET 金鑰，你可以直接使用：

```
renting-kpop-phone-cron-secret-2024-08-03-16-30-00
```

## 🔧 **如何設定到 Vercel**

1. 前往 Vercel 儀表板
2. 選擇你的專案：renting-kpop-phone
3. 點擊 Settings → Environment Variables
4. 新增環境變數：
   - **Name:** CRON_SECRET
   - **Value:** renting-kpop-phone-cron-secret-2024-08-03-16-30-00
   - **Environment:** Production, Preview, Development（全選）

## ⚠️ **安全注意事項**

1. **不要分享這個金鑰**給其他人
2. **定期更換**金鑰（建議每 3-6 個月）
3. **使用強密碼**（至少 32 個字符）
4. **包含專案名稱**以便識別
